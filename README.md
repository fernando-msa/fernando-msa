## 🚀 Projetos em Destaque

### 🛡️ SecPolicy HAMA

Sistema para gestão mensal de conformidade com políticas de segurança baseado na ISO/IEC 27001.

* 📋 Checklist estruturado com 22 controles
* 📊 Pontuação automática em tempo real
* 📄 Geração de relatório PDF
* 🔄 Fluxo de aprovação (Analista → Gestão)

🔗 https://github.com/fernando-msa/secpolicy-hama

### 🌸 MOB App — Método de Ovulação Billings

Aplicação web PWA para registro de observações do ciclo, com foco em privacidade e simplicidade.

* 🔐 Autenticação com Supabase
* 🛡️ Row Level Security (RLS)

* 🌍 Deploy gratuito

🔗 https://github.com/fernando-msa/mob-app
