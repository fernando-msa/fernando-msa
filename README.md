### 👋 Sobre mim

Sou **Analista de Infraestrutura** na HAMA (Aracaju/SE) e estudante de **Engenharia da Computação**, com foco na interseção entre infraestrutura corporativa, automação e desenvolvimento web.

No dia a dia gerencio ambientes Windows Server/Linux, sistemas de backup com **Bacula**, GLPI e automatizo processos internos com Google Apps Script e PowerShell. Nas horas vagas desenvolvo aplicações web com Next.js, TypeScript e Supabase.

- 🏥 Infraestrutura corporativa na área da saúde (HAMA)
- 🔧 Automação de processos internos com Google Apps Script
- 🌐 Desenvolvimento web full-stack com Next.js + Supabase
- 🧩 Extensão de navegador publicada na Microsoft Edge Store e Firefox Add-ons
- 🎓 Estudante de Engenharia da Computação
